# 🏥 Determination of Optimal Predictive Model for Customer Attrition

## 📌 Overview

This project investigates the risk determination and feature identification of customer attrition

## ✅ Purpose

Client company will use this model to efficiently and effectively target marketing efforts

## 🎯 Problem Identification   

Using a client-provided data set of 10,000 customers, I will:

### Develop an Analytic Plan
* Propose a supervised classification problem
* Identify the target
* Determine necessary data processing
* Determine features to be considered and created if necessary
* Identify expected analytic and informational outcomes

### Perform Preliminary Analysis
* Perform data processing steps
* Create additional features as needed
* Train one logistic regression model and one kNN model
* Evaluate models 
* Determine future data processing needs and feature engineering steps

### Conclude and Present Final Results
* Revise preliminary model as needed
* Compare performance of logistic regression, kNN, naive Bayes, random forest, xgBoost models
* Select model most appropriate for this business need
* Determine most important features influencing customer attrition
* Discuss how the model and feature importance findings can be used in practice.
